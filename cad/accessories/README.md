# 可逆附件与测量辅助

`measurement-scale.svg` 是1:1打印校验尺/方向靶，不是精密量具。打印100%，量实100mm校验线并记缩放偏差。

`rb67_instax_square_viewfinder_mask` 预期为可逆、可卸、不贴胶伤屏的附件。实际文件生成前需M03/M18测实际capture polygon、screen有效域、光轴/旋转轴差、镜像/旋转映射和边缘视差；不能仅画62mm正方形后宣称可装。当前不提供虚构尺寸mask或STL。

三点深度桥/片盒巢可3D打印的主体尺寸待M02/M04；实际接触基准和表杆配合要按所用仪器测量。打印件不得作为未经校准的0.05mm基准。
