# 测量计划：RB67、旋转接环、Instax Square

R0 / P0，2026-10-07。当前所有物理接口、片盒外形、乳剂偏置和滚轮工作参数均为 **MEASUREMENT_REQUIRED**。没有实物量测，不能填写 VERIFIED_MEASUREMENT。此文件也是给用户的具体测量请求。

## 坐标、单位与可追溯记录

RB 坐标 R：相机后方看向镜头，X 向观察者右，Y 向上，Z 向远离镜头方向。原装旋转接环后背三点稳定接触面为 R 的 Z=0 参考面；光轴与该面的交点为 X=Y=0。旋转轴在此面中的位置另记 c_rot=(ROTATION_AXIS_OFFSET_X, ROTATION_AXIS_OFFSET_Y)，两值都待测；不得假设光轴与旋转轴重合。参考面必须注明是哪个面，不能混用槽底、后盖表面和锁扣面。

片盒坐标 P：曝光面朝观察者，确认出片口后定义 U 跨出片口，V 沿出片方向，W 垂直片面向片盒后方。产品图的“宽/高”不等于 U/V。记录 P→R 的旋转、平移和 front/back，不只抄三个外形数值。

每条原始记录包括：样品 ID、机身/接环版本、胶片批号、满/半/空片堆、温湿度、仪器型号/分辨率/校验、测点照片编号、读数重复至少三次、载荷状态、平均与范围、估计扩展不确定度、操作者、日期。卡尺分辨率不等于测量精度；照片尺、FDM 夹具和手机扫描不能宣称 0.05 mm 精度。异常值保留并说明，不能只留下最好一次。

## 已有源模型：先校核，避免从零量全部外形

新增来源、许可与下载状态见 [open-cad-sources.md](open-cad-sources.md)。本地参考文件和名义包络见 [cad/reference](../cad/reference/README.md)。

M02 从 CC BY G 接收座识别配合面，分别登记原接环与原卷片后背承载面、锁条搭接。优先量两锁条跨距/厚度/轴向高度、三个刚性接触基准、完整锁条行程、暗板联锁与避让。不能用接收座网格负形自动生成 V2 后背；5.15 模型单位的总厚不是 A→曝光面。机身/接环/原后背型号须三项分别记录。

M04 可从已归档的 C01 相盒参考及 [STEP 预览](../cad/cartridge/R0_reference_only/README.md)开始。先校核三轴包络、前壳突出量、出口和拾片窗最小净空，记录批号与模型遗漏；不必先测全部非关键圆角。STL 无单位，不能从相纸规格缩放片盒。预览实体可用于浏览和比对，尚不能作为制造或焦平面定位依据。

M03 的 A→原有效曝光面、接环多截面空腔与通光轮廓，M05/M06 的真实受压曝光面/满半末片变化，以及 M20 的旋转净空，没有被网上模型解决，仍是必测项。压片板/胶片支承轨/前窗/入射表面都不直接等于有效感光面。

三点基准取实际承载面，不取密封泡棉、装饰面或包络极值；记录锁紧和密封压缩状态。源模型原点/轴不等于项目 R/P 基准。具体校核顺序见 [model-fit-plan.md](../cad/reference/model-fit-plan.md)，原始记录用 [source-fit-checks.csv](../experiments/source-fit-checks.csv)。

## 建议工具与安全对象

外形：校验过的数显卡尺、平直基准板、方尺。深度/倾斜：深度千分尺或桥架加百分/千分表、量块/塞尺、稳固支架。薄片：低测力测厚仪，避免压扁未显影片的药包。力：可校验的小量程测力计、位移台。动态：手机高帧率视频和带时间戳电流采样。

先用空片盒与已显影片。不要在正常照明下打开仍有可曝光胶片的后门；暗袋不能自动防机械损坏。不得剪切、刺穿、拆散未处理真实相纸；厂商安全说明见 [SQ20 手册](https://www.instax.com/support/pdf/instaxsquare_sq20_manual_01.pdf)。任何压片或厚度实验只施加受控小力，不能触发药包破裂。

## 可打印测量辅助件与制造前置条件

提供 [measurement-scale.svg](../cad/accessories/measurement-scale.svg)：1:1 的打印比例检查尺和方向靶标。使用“实际大小/100%”，量测打印后的 100 mm 校验线，记录打印缩放误差；它只帮助拍照定位和光学方向测试，不能替代精密仪器。

建议的三维夹具分别为：三点深度桥、片盒重复定位底座、压片位移台、可观察拾片平台。接触相机/片盒的尺寸依赖 M02/M04，当前不导出虚构 STL。FreeCAD 参数方案：桥跨 = 实测边缘跨度 + 两侧安全支承余量；表孔按实际仪器杆径；底座坐标由片盒三个非弹性基准面给出；压垫避开图像及拾片窗。每个余量是可调设计参数，不是片盒测量值。

开放/透明拾片平台只用于假片或废片；真实未曝光胶片测试必须另装可拆避光罩，不能为可观察而牺牲遮光。

## 参数更新与可制造门槛

1. 原始读数追加到 experiments，不覆盖旧值；revision、instrument、sample_id 必填。
2. 更新中央参数 value、tolerance、provenance、source、sample 条件；测量后只有经复核才改 VERIFIED_MEASUREMENT。
3. 同一现象的不同定义分别记录：壳到外层 ≠ 壳到乳剂；无载 gap ≠ 过 pod gap；已显影片 ≠ 原始相纸。
4. 需要的未知尺寸未闭合时，计算返回 UNKNOWN，不生成制造模型。只有参数链、变差和各接口都明确才进入 CAD source 与 STEP/STL。
