# 原焦平面、原旋转接环与标准 Instax Square 片盒：可行性核查

核查日期：2026-10-07。本文是 V2 的前置工程研究；没有完成背设计、可制造接口图或可直接打印的数值几何。

**FEASIBILITY RESULT: UNCERTAIN — MEASUREMENT REQUIRED**

公开一手资料尚不能证明以下条件能同时满足：使用未经改动的标准 Square 片盒、保留对应机身的原厂旋转接环、在原感光面曝光、保留横竖旋转、在有剩余相纸时拆下且独立防漏光。已有背的成功拍摄说明 Instax 与 RB67 能组成系统，但它们的接口路线、供体依赖和密封条件与本项目不同。当前没有测得干涉，因而也没有证据把本路线判为物理失败。

本研究中的 `null` 表示尚无可用测量；不得换成 `0`、网上近似值或 CAD 默认值。`MEASUREMENT_REQUIRED` 是准入阻塞条件。坐标原点的零值只是定义，不是“零间隙”的测量。

## 4. 可复查的坐标与基准定义

这些定义是测量约定，不是已获知的固定尺寸。

- **机身系 R：**机身固定，与 measurements.md 的 R 相同。观察方向为从相机背后向镜头看；选定原接环横向定位端为 `θ = 0`，横竖端之间旋转角记为 `θ`。实际旋转方向及止挡以该接环记录，不假设每个改装件都沿同一方向。
- **基准 A：**原旋转接环后侧让卷片背刚性定位的真实承靠面。用可重复的三个刚性接触区建立平面；不能把毛毡、海绵、装饰外壳、塑料片盒盖当成承靠面。`z = 0` 在 A，`+z` 指向相机后方。
- **原点 O_R：**实测光轴与 A 的交点；`+x` 向背后观察者右侧，`+y` 向上。旋转轴在 A 中的位置另记 `c_rot=(ROTATION_AXIS_OFFSET_X,ROTATION_AXIS_OFFSET_Y)`，当前两者均为 null mm。原旋转轴不自动等于光轴、孔口中心、卷片画框中心或 Square 图像中心。
- **随动接环系 Q：**原点在 c_rot，坐标轴随接环旋转，用于装配包络。R 中的点旋转须计算 `p_θ=c_rot+R_z(θ)(p_0−c_rot)`，不能直接围绕光轴旋转全部模型。完整三维轴线方向/倾斜亦须测量后加入。
- **基准 B、C：**在 A 内用 G-lock 的可重复定位特征建立横向位置与方向，记录实际接触位置；锁紧机构负责压紧时，不自动把浮动的锁扣当成精密定位边。
- **原有效面 R：**正确装载且正常压紧的原厂参考卷片背在曝光时的感光有效面；记 `z_R(x,y,配置)`。参考背仅作为量具对象，不拆取零件作供体。必要时对照经校准的焦屏光学像面；老相机焦屏 / 镜箱误差不能归咎于新背。
- **片盒系 P：**选标准片盒曝光侧的可重复刚性表面与侧边定位特征。记录黄色标记、出片口、拾片入口、突起和包络。该平面到在位未显影相纸感光有效面的距离记 `h_E(n,x,y,F,T,姿态)`，`n` 为剩余张数，`F` 为正常装夹载荷，`T` 为温度。
- **图像中心 E：**用实际曝光可见区域边界求中心 `c_E`，不是取相纸 / 片盒矩形的中心。**目标中心 T：**用原机身与接环的实测通光域、实际图像覆盖和取景映射求 `c_T`。片盒横向定位必须满足 `c_E → c_T`，不得为片盒外廓居中而牺牲图像位置。

成片表面、片盒前唇、黑色保护盖、被压平的废相纸均不是可直接替代 R 或 E 的基准。Instax 的成片层与感光层之间存在光学 / 物理层次，原厂上述资料未给出层厚与折射参数。若只能测到可见表面，必须标为 `surface_proxy`，相关层偏置与有效焦面仍为 `null`；几何测量配合真正胶片实拍才能验证对焦。不得用“重新对焦拍清楚了”证明胶片仍在原焦平面。

## 5. 标准片盒能否抵达原感光面：必须先解的约束

以下是本文自己的几何推导，尚无数值代入。

令片盒基准 P 在相机系的轴向位置为 `z_P`，原焦面为 `z_R`，有效层深度为 `h_E`。原焦平面条件是：

`z_E = z_P + h_E = z_R`，所以 `z_P_required = z_R − h_E`。

这说明“在接口后多加一块板”并不是天然有效的办法。板变厚或片盒后移会增加 `z_E`；如果片盒深度要求 P 位于 A 前方，片盒的前框、边唇或壳体必须有实际空间进入原接环凹腔。只有图像窗能通过不代表整个标准片盒前框能通过。这里不允许通过取出单张相纸、裁切片盒、改造片盒前框、删除原接环或移动机身 / 焦屏来补偿。

### 5.1 轴向局部干涉不等式

在经过图像中心对齐和出片方向定位后，令：

- `f_C(x,y)`：标准片盒在该投影位置最靠镜头的实体表面相对 P 的有符号 z 坐标；不是只测曝光窗中央。
- `b_R(x,y,θ)`：机身 / 原接环实体在 R 系中该位置最靠后的障碍面 z 坐标。仅在实际实体重叠的投影区域 `Ω_overlap(θ)` 定义；通光孔中的空洞不算实体。
- `c_req(x,y)`：由制造、变形、装夹和禁止接触部位决定的要求净空，当前 `null`。
- `U_g`：片盒、机身、测量、装配、旋转偏摆和受载变形的最坏组合不确定度，当前 `null`。

必要条件为：

`g(x,y,θ,n) = [z_R − h_E(n)] + f_C(x,y) − b_R(x,y,θ)`

`g_L = min_{配置,θ,n,(x,y)∈Ω_overlap} g − U_g ≥ c_req`。

如果某处存在翻边 / 倒扣 / 多层表面，单值 `b_R` 或 `f_C` 不适用，必须用完整三维实体与有符号距离检查，不能把该点省略。完整检验写为：`C_standard_at_required_plane ∩ BODY_ADAPTER_forbidden = ∅`，并在全部状态中满足规定最小净空。本文不输出一个缺少测量的数值“最薄适配板”。

### 5.2 三种必须区分的结果

1. `g_L ≥ c_req` 且完整体积检验通过：证明测过的配置具有几何可行性；仍需焦面、联锁、旋转和防漏光验证。
2. 下界不合格，但误差区间跨越可接受边界、未测关键位置或量具能力不足：继续 `UNCERTAIN — MEASUREMENT REQUIRED`。测量不充分不是已证明物理失败。
3. 在原焦面位置，连最有利上界也发生实体重叠，例如 `g_U < 0`，且在所有允许的横向姿态 / 出片方向均存在不可消除的碰撞：`FAIL — PHYSICAL INTERFERENCE`。只有改变自制件、不改硬约束的修改才可能挽救路线；拆接环、改片盒或后移焦面属于更换路线，不能记成本路线通过。

### 5.3 通光是独立约束

即使片盒实体能装入，也须检查由曝光区域每一点至实际镜头出瞳的光线锥是否被接环、暗插框或片盒窗口截断。标称 62 × 62 只是相纸可成像区；实际曝光区域是这些约束的交集：

`I_actual = I_film ∩ I_pack_window ∩ I_adapter_clear ∩ I_body_clear ∩ I_lens_coverage`。

这些域、中心和边缘位置目前均须实测。不同镜头、近距皮腔伸长、出片方向和旋转状态可能改变光线锥边缘；不能只透过裸接环拍一张孔口照片就证明完整覆盖。

## 6. 焦面公差链与垫片校准

令未来测量夹具中的 P 定位深度为 `d_AP`，轴向校准垫片为 `s`。本坐标中正垫片使 P 向后移动时：

`Δz(x,y,n) = d_AP + s + h_E(n,x,y) − z_R(x,y)`。

如果实际垫片安装位置产生相反方向，必须改写符号并实测灵敏度，不沿用上式。`s` 目前为 `null` mm，不能先填默认打印厚度。

最坏焦面误差预算包括 A 接触与重复装配、G-lock 压紧、定位件加工、垫片厚度、片盒批次、正常压紧下的片面位置 / 平整度、横竖姿态、热漂、背重量 / 电机振动引起的挠曲、参考原背与测量误差。几何公差必须有符号和测量方法；不知道的公差不可当零。可先保守相加各项有界误差；没有统计独立性证据不能用 RSS 缩小预算。

将平面误差写成 `Δz = a + p_x x + p_y y + w(x,y,n)`：`a` 是整体偏移，`p_x,p_y` 是倾斜，`w` 是局部平整度及张数状态变化。均为待测，不是数值拟合结果。均匀垫片只能校正整体偏移；中心清楚而角落不清楚可能是倾斜 / 翘曲 / 光学像场问题，不能继续加厚整片垫片处理。

验收容许量 `T_z` 必须先由画质要求确定。在简单几何光锥中，离焦斑直径可写成 `d_blur ≈ 2|Δz|tan(u)`，`u` 是当地像方半锥角；这是推导而非 Instax 的公布性能。`u`、允许弥散斑和胶片可辨识目标未定，故此处不能给出统一的 mm 容许量。大光圈、近距、边角和使用镜头中的最苛刻条件必须覆盖；不能靠缩小光圈隐藏误差。

校准流程：

1. 检查原机身、对应原接环和参考卷片背的重复定位，先证明焦屏与 R 的映射可靠。用刚性校准夹具让**磨砂面**落在实测 R；不要按玻璃外表面或玻璃总厚度定位。
2. 使用在位标准片盒，以正常装夹方式测满盒、中段和末张的 surface proxy / 有效面；不压 F2 禁止按压的矩形孔，不人为改变片盒弹性系统求“可装”。机械层深度不足以证明有效面时，记录该限制并继续实拍校验。
3. 在保持机身焦屏、镜头设置和被摄物位置不变的条件下，测 `Δz` 与姿态变化。先以量测估计调整方向，再以已测厚度的可拆垫片迭代；每次记录垫片实厚、位置、锁紧状态和结果。
4. 校准后重新检查片盒前框净空、暗插行程和旋转路径。向前校正焦面可能减少干涉间隙；这两个项目不能分开宣布通过。
5. 镜头全开进行近摄、人像距离和无穷远三类对比；距离和镜头实值填入测量记录，本文不给假定距离。近摄覆盖较大皮腔伸长、人物距离覆盖常用条件，无穷远用足够远的目标或校准准直目标；不能只看距离标尺的 ∞ 标记。
6. 每类比较焦屏 / 校准 R 磨砂面与真实 Instax 照片，画面含中心及边角细节和有方向的文字。双姿态、装卸重复、满盒到末张均需覆盖。将同设置下照片锐度与边缘位置记录；反复重新对焦使照片清楚不算原平面保持证据。

此处使用的参考背、校准玻璃和量具仅用于测量。它们不会成为 V2 的供体部件或交付物。最终垫片范围、分辨率和接触区由实测后确定，当前均为 `null`。

## 7. 图像中心、方向与可逆取景遮片

片盒有出片边、拾片路径、相纸边框和定位特征；标准资料没有公布它们相对图像区的坐标。Square 画面为正方形，旋转仍会改变边框方向、出口位置、手柄 / 三脚架干涉和拿取方式，因此不是“方形就无需检查旋转”。

先测出 `I_actual`、其中心 `c_E → c_T`、旋转轴偏心和焦屏上的实际对应区域，再确定取景辅助边界。原厂卷片背的取景红线是各原画幅的标识，不可直接当 Square 遮片尺寸。**R0 可用无损、可移除的临时取景标记；不得刻划 / 改高焦屏。**在焦屏尺寸、实际曝光区和映射未测完前，禁止发布带固定尺寸的打印取景遮片。遮片必须不改变焦屏承靠高度、不妨碍接环原有机构；其厚度、窗口和位置当前均为 `MEASUREMENT_REQUIRED / null`。

光学方向要单独记录：直接镜头投影在物理像面发生上下 / 左右倒置；腰平取景的观视方向、曝光所朝向的胶片面和最终观看成片的那一面会影响观察到的方向。不能只根据“Instax 从背面曝光”或取景器看起来左右颠倒，推断成片一定镜像。使用不对称靶标，例如标注 `TOP / LEFT / RIGHT`、箭头和可读文字，记录机身 / 片盒 / 出口姿态与成片观察面，验证旋转前后实际映射。方向校验结果当前为 `null`；不要承诺镜像或非镜像输出。

## 8. 原旋转接环的连续旋转包络

保持接环的 90° 两端定位只是最初条件。所有新背部件、插入或抽出中的暗插、操作手指需要的空间、电池 / 线束、正在排出的相纸都应按状态形成体积 `V_back(state)`。固定机身、手柄、快装板、云台及其操作件构成 `V_fixed(configuration)`；实际安装的附件组合必须登记。

围绕实测旋转轴 c_rot 将体积旋转：`V_sweep = union_{θ∈原接环合法连续行程} {c_rot+R_z(θ)(p−c_rot): p∈V_back}`。必要条件为 `V_sweep ∩ V_fixed = ∅`，并在全程保持规定净空。仅测试 θ 两端不能覆盖中间的对角扫掠。片盒若相对轴偏心，必须旋转其真实坐标；不能用一个以光轴为圆心的猜测圆柱简化。

分别核查：装妥且暗插收纳状态的合法旋转；暗插完整插入 / 抽出操作；正常出片及片头尚未拿走；充电 / 供电线的状态；横竖姿态的自重挠曲。是否允许出片中旋转应成为后续系统的明确限制或要求；本研究不预先宣称允许。机身原联锁要求到位定位及相应操作，测试不在释放按钮按住时强转接环。[Mamiya 原厂操作条件见 M1–M3](https://www.manuallib.com/download/pdf8/MAMIYA-RB67PROSD-INSTRUCTIONS.PDF)。

R0 外廓、质量、重心和弯矩模型即使暂时有估值，也只能标为 `ESTIMATE_ONLY`。弯矩近似 `M = m g r` 的输入必须实测后才能签署；静态估值不能替代旋转定位重复性、联锁功能或受载焦面位移测量。

## 9. 中途拆背：暗插并不自动封闭所有光路

F2 的原厂限制表明相纸未用完不能敞开片仓。V2 的“中途拆背”必须是**整个背保持片仓关闭、全部剩余相纸留在标准片盒中**；不是在亮处从背中取出半盒片。黑色保护盖在装片后会被排出，不是每次中途拆背都仍存在的遮光屏障。[Fujifilm SQ6 原厂说明书，英文印页 30–33](https://asset.fujifilm.com/www/us/files/2020-05/5becc72ba66b40fb541d9db9dfe6aa45/instax_square_sq6_manual_01.pdf)

以下是工程需要逐条封堵与验证的光路，不是已完成的密封结构：

| 光路 | 待验证条件 / 典型失效 |
|---|---|
| 曝光窗 → 在位首张 → 片盒内 | 暗插完全遮盖全部 `I_actual`；四周边界、角部和插到底端不能有直射或反射通路；暗插形状和行程尚未测。 |
| 暗插槽 → 暗插两面 / 两端 → 曝光腔 | 插入时、抽出途中和完全抽出后分别防漏光。没有暗插时仍必须由背自身的槽密封承担遮光；“插着时没漏”不能代表拍摄状态没漏。 |
| 背 / 接环接缝 → 曝光腔 | 在机身上依赖接环的密封与背自身独立密封必须分开。拆下后接环不再盖住前端，必须重新评估所有开放接口。 |
| 片盒拾片入口、侧边空隙、后盖接缝 | 与整个片盒的剩余片堆相关；只覆盖画面中央可能无法封住这些路径。不要把标准片盒当作黑盖排出后仍完全自密封的容器。 |
| 出片口 → 滚轴 / 排片通道 → 片盒 | 待机、片头运动、相纸夹于滚轴、卡片停止、末张后各状态均需验证。滚轴的显影压力功能不是已获证的光阱功能。 |
| 壳体、计数窗、按钮 / 指示灯、螺孔 | 外壳材料与最薄壁、接缝及内部 LED 均需验证；外观黑色和涂黑不是测量结果。C2 记录的是真实透光失效，不能直接拿其材料性能数值替代本壳体。 |

暗插要让整背在拆下后独立保持防漏光，还须在装好但暗插抽出时不妨碍曝光、在完全插入时不触碰片面 / 拾片路径、在移动中不过度摩擦或产生碎屑，并对 Pro-S / SD 的原机构维持正确状态。未来任何联锁的尺寸、力、行程均须由实测定义；软件提醒不能替代光阱。

出片口的光阱应按光学边界条件讨论：外部光线不能经无遮挡的视线或过强多次反射达到剩余相纸；结构同时必须允许未显影片通过，不能以在显影区额外加压 / 刮擦换取遮光。迷宫、柔性唇、刷 / 毛毡等只是待试的机制类别，本研究未选择材料、厚度或可制造结构。

NONS 本人的说明明确其暗插仅临时降低漏光、拆背须立即进入防光袋 / 盒，因此它能提示验证风险，但不能作为 V2 独立中途拆卸能力的验收证据。[NONS 原厂产品页](https://nonscamera.com/products/nons-instant-back-rb67)

防漏光试验必须有未曝光对照，并覆盖满盒、中段、末张、双姿态、暗插三种状态、拆背、出口朝不同强光方向以及合理可预见的出片中停机状态。记录光源光谱 / 照度、距离、暴露时长、温度、相纸批次和均匀扫描设置，当前所有输入与可接受雾化量为 `null`，先定义目标再选择试验条件。以黑暗中顺利出片或一张正常照片不能宣称漏光通过。没有完整通过前，不给出“可以放在桌上存半盒”的操作承诺。

- **UNCERTAIN — MEASUREMENT REQUIRED**：关键尺寸、有效面、覆盖、密封或不确定度缺失 / 跨越边界。这是当前唯一有证据的总判定。
- **FAIL — PHYSICAL INTERFERENCE**：测量已证明在原焦面、标准完整片盒、保留正确原旋转接环的允许姿态集合内存在不可消除实体干涉。仅未测、焦点偏差或一张漏光照片均不足以用这个标签。

移去原旋转接环、改造标准片盒、移动焦屏 / 机身基准、用后移焦面并重新对焦、或者要求中途拆背后立即放入黑袋，都改变了当前要求；须另立路线，不能列为这个 V2 的通过条件。下一步最有价值的工作是 P1–P4：先量出 `z_R`、`h_E` 与片盒前框 / 接环凹腔的真实关系，再决定是否值得进入其余实验。
