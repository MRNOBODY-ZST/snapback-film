# R0 故障定位与恢复原则

这是尚待台架验证的故障流程，不能称为已验证产品维修手册。先 STOP，保留状态、传感器、A/B 电流、版本和片盒批次；不要以重置计数或反复 EJECT 消除故障。

| 现象 | 检查顺序 | 后续验证 |
|---|---|---|
| 未拾到片 | 片盒在位/定位 → 实测访问窗 → 接触深度/行程 → 负载与回程 | 假片首/中/末分组，力—位移与慢动作录像 |
| 双片 | 实际分离界面 → 指尖深度/宽度 → 剩余片堆扰动 → 压片状态 | 不只降低电机速度；独立验证分离与拾片 |
| 入口已触发但片不走 | S4 不等于夹持；查桥接长度、进入角、辊隙与牵引 | 独立夹持证据、轴转角与真实片位移 |
| 药包不破/边角无药 | 真片批次/温度 → 左右载荷 → 跳动/平行度 → 材料与速度 | 真实片受控曝光与统一扫描，不能靠假片判断 |
| 周期性条纹 | 缺陷间距与滚轮周长 → 偏心/污染 → 表面/套厚 | 记录轴相位，检验诊断假设而非立即加压 |
| JAM / 片停半途 | 同步电流/阶段/位置，保持剩余片遮光 | 最多一次已验证安全区 A 回退，夹持/破包后不自动反转 |
| CYCLE_UNCERTAIN / SERVICE | pending、写入/CRC、复位原因、现场片位置 | 人工核对；home 清空不能证明片已完整处理 |
| 计数不可信 | 黑盖和普通片提交事件、断电记录、换盒确认 | 禁止静默改为 10 或继续普通 EJECT |
| 焦点不符焦屏 | 原机焦屏/R 基准 → 首/中/末有效层 → 平面倾斜 → 装卸重复 | 受控靶和实测垫片；不能用缩光圈隐藏误差 |
| 雾化 | 内部 LED/探测光 → 暗插槽 → 出口 → 门/接环/服务缝 | 黑暗对照与逐路径封堵，双姿态/中途拆背复验 |
| 低电压停机 | 电池 → 保护 → VM → 线束压降 → 峰值电流 | 先处理未完成片，不因电压恢复自动再次送片 |

卡片服务时先停止并禁止再武装，隔离外部光线后按台架结构手动释放滚轮预压/取走失效片，核查未送入第二张和片堆状态。释放方法随实际台架与后背结构验证后补充。门开必须禁用两电机；服务模式不允许绕过此联锁。未确认安全的片材位置不得点动。

出现外漏处理液时终止该次试验，按胶片原厂处理指导清洁并检查滚轮污染；不剪开药包或制造替代化学品。维护和材料相容性须记录；清洁液不预设为任意溶剂。更多失效分析见 [fmea.md](fmea.md) 和 [roller-development.md](roller-development.md)。
