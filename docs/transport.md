## 2. 共同的行程、力与防双张条件

令 `g` 为最前张药包前缘至第一咬合线的沿片距离，`h` 为爪对片的有效推进行程，`m_h` 为装盒位置、回差和弹性造成的行程余量。需要：

```text
h >= g + m_h
F_pick(y,n) = F_exit + F_flap + F_guide + μ_inter N_stack + m_eff a
F_design >= max_y,n{F_pick(y,n)} + F_uncertainty
T_cam,load ≈ F_pick (dy/dθ) / η_cam
```

`n` 是剩余胶片数量。各力项只是用于组织测量的模型，不能把未知摩擦系数填入通用塑料数据后当作实测值；黑盖初始化也计入最大负载。测力夹具应测整条力—位移曲线，而非仅在终点读一个数。爪只负责把片交给辊，正常行程不等于整张片长。

防双张不能只依赖一个“薄爪尖”。定义 `p(n)` 为最前张与次张尾缘的实际可分离法向距离，`e_tip` 为爪尖的有效进入厚度，`u_z` 为片面、爪和导向的合成误差，则存在单张选取窗口的必要几何条件是：

```text
e_tip + 2 u_z < min_n p(n)
0 < 单张尾缘的实际挂接量 < 不触及次张的深度
```

若测得 `p` 接近零，上式不能靠名义片厚度证明，需要能够抬起/分离尾缘的接触轨迹或柔顺指尖。`p` 不是单片全厚。片盒本身的出口限位和挡片也参与分张，不能为减阻而随意剪除。回程时爪尖必须先在 `z` 方向脱离，随后在 `y` 方向回到原点；其轨迹不得拉回已经被辊抓住的片，也不得再次挂住补位的次张。

片堆法向力采用实测函数 `N_stack(n,δ)`，其中 `δ` 是后盖压片部件的位置。若暂时用线性弹簧近似 `N=N0+kδ`，仍须记录首张到末张的有效位移和迟滞。压片力过低可能导致尾缘位置漂移，过高可能增加出片阻力和片变形；这两项是待试验的竞争条件，而不是已经知道的合格范围。

## 3. 三种拾片机构的独立比较

下列公式均为理想运动学/功守恒推导，不代表任何供体机构的尺寸。制造性判断是原型决策假设，须用试件复核。

### 3.1 凸轮驱动、带法向柔顺的滑动拾片指

可采用转动凸轮驱动 `y` 滑块，另用导向面或第二轮廓使可换指尖在待机和回程时离开片面。凸轮的一周明确包括进片、交接、脱离、回程和原点停留。为避免把图纸上的折线轮廓当作可制造曲线，先用光滑位移函数：

```text
上升段：u=(θ−θa)/β，0<=u<=1
y=h [u−sin(2πu)/(2π)]
dy/dθ=(h/β)[1−cos(2πu)]
v=ωc dy/dθ；a=ωc² d²y/dθ²（ωc 恒定时）
v_peak=2 h ωc/β
|a|_peak=2π h ωc²/β²
回程段可以使用同类函数反向；高位/原点停留段 dy/dθ=0
```

`β` 是上升占用的弧度。增大 `β` 会降低相同转速下的速度和加速度峰值，但压缩辊在一周内剩余的运输窗口。对于无偏置径向平动从动件的简化凸轮：

```text
tanα ≈ (dy/dθ)/(Rb+y)
N_follower ≈ F_y/cosα；侧向力 ≈ F_y tanα
```

偏置、摆杆和滚子半径改变真实压力角，须按最终几何重算。法向预紧也须使从动件在最不利加速度时保持接触；不能用增加预紧补偿过陡轮廓而不检查磨损。通用滑动磨损比较可用 `V ≈ K N s_slide/H` 作方向性模型，`K` 与材料/润滑/粉尘相关，不能由此预测寿命。滚动从动件减少某些滑动距离但仍有轴承、局部接触和回差风险。

优势：行程与停留、指尖进入/退出时序都能分别设计；模块化指尖便于研究尾缘接触。成本：轮廓公差、导向平行度、从动件侧力和轮廓磨损需检验。暂列早期拾片首选。

### 3.2 曲柄滑块

无偏置、连杆长 `l>r`、曲柄半径 `r` 时，可选从最外死点起的推进行程：

```text
y(θ)=r(1−cosθ)+l−sqrt(l²−r² sin²θ)
h=2r
v=ωc dy/dθ
sinφ=(r/l)sinθ
连杆轴力≈F_y/cosφ；滑块侧向力≈F_y tanφ
T_driver≈F_y(dy/dθ)/η + T_friction + J_eq dωc/dt
```

几何在两个死点瞬时速度为零，但并没有有限角度的机械停留。若要等待辊接片，需要停电机、增加槽连杆/单向机构，或另加脱离装置；停住电机后的再启动力也要测。死点附近不能用除以 `dy/dθ` 的理想机械优势推断无限可用推力，关节摩擦、屈曲和结构刚度会先成为限制。

优势：轴承、直杆和曲柄容易用通用件制造，行程参数直观。成本：不能独立改变上升、交接停留和回程；较短连杆增加侧向力；销孔磨损会改变指尖高度。适合可调行程台架和第二个对照机构，不是未经验证的最终紧凑方案。

### 3.3 直接循环拨指与 Geneva 间歇机构

直接在轮上设置柔顺拨指，其尖端的理想圆轨迹可以写成：

```text
y=y0+r_f sinθ；z=z0−r_f cosθ
在实际挂片角域[θe,θh]内，h_eff=r_f(sinθh−sinθe)
v_y=r_f ωc cosθ
T≈F_y(dy/dθ)+F_z(dz/dθ)+T_loss
```

必须验证圆弧同时满足挂片深度、前推、主动退出、回程净空。整周都靠摩擦扫过片面可能刮片或触及次张；柔顺指尖的接触力近似 `F_z=k_f δ_f`，而其弹性、疲劳和永久变形未知。不能因为轮子一转就假定它只拾一张。

Geneva 的主要功能是间歇转位，并不直接生成所需直线往复。标准外槽 `n` 槽的理想几何中，令 `λ=a/c=sin(π/n)`，驱动销轨道半径为 `a`、两轴中心距为 `c`：

```text
有效啮合：|θ|<=acosλ
ψ=atan2(λ sinθ,1−λ cosθ)
dψ/dθ=λ(cosθ−λ)/(1−2λ cosθ+λ²)
每输入一周，输出只转位 2π/n
输入停留占比=1/2+1/n
若输出再驱动爪：T_driver≈F_pick (dy/dψ)(dψ/dθ)/η
```

因此“一输入轴周 = 一输出凸轮整周”不是 Geneva 本身的性质。还需增速传动或新的轨迹转换，并说明一次分度如何完成推—退—回原点。啮合出入时加速度切换、销槽间隙和锁止面接触可能产生冲击；销槽磨损会改变时序。相对于简单凸轮，它增加的零件和公差是否值得，应在台架上证明。暂不作为早期首选。

| 比较项 | 凸轮滑动指 | 曲柄滑块 | 循环拨指 / Geneva |
| --- | --- | --- | --- |
| 行程与停留调节 | 可分别调节轮廓各段 | `h=2r`；无有限机械停留 | 拨指由圆弧限制；Geneva 只有转位停留 |
| 单张接触/回程脱离 | 可另设 `z` 轨迹和卸载段 | 需额外脱离机构 | 需严格验证圆弧；Geneva 本身不分张 |
| 交接速度 | 可定制上升曲线 | 由 `r/l` 和曲柄转速决定 | 有效角域/输出转位曲线决定 |
| 负载与磨损控制 | 压力角、从动件接触 | 连杆角、导轨侧力、销孔 | 指尖疲劳或销槽冲击/回差 |
| 制造与调试 | 可换凸轮、可换指尖 | 通用杆/销件便于做对照 | 定相、锁止、公差链更复杂 |
| 当前判断 | 优先进行可调台架验证 | 保留对照 | 保留研究，不直接定型 |

## 4. 一凸轮周与辊的运输长度条件

[US6490414B2 的 Related Art](https://patents.google.com/patent/US6490414B2/en)明确把完整出片循环与一凸轮周联系，并指出打滑可能导致固定周数不足。本项目采用以下更严格的判据。

令 `R` 为辊在负载下的有效半径，`k=ωr/ωc` 为辊对凸轮的转速比，`θbite` 为实际咬合的凸轮相位，`θstop` 为机械原点的停止相位，`s_max` 为已测的最坏滑移比例，`L_remaining` 为咬合瞬间尚需通过辊的片长，`m_L` 为确认尾缘完全通过所需的运输余量：

```text
R k (θstop−θbite)(1−s_max) >= L_remaining+m_L
k >= (L_remaining+m_L)/[R(θstop−θbite)(1−s_max)]
单周机构：θstop<=2π，且爪必须已退出并回原点
```

只有在咬合从循环起点就建立时，才能用“一周的辊周长乘转速比”估算；一般不能直接令 `πD k >= 86 mm`。`L_remaining` 取决于初始位置和咬入深度，不是片盒长度。沿片方向的 `L_parallel` 要用实物确认药包所在边后定义，不能仅凭网页中的 W/H 标签指定。

交接时还需控制辊与推爪的速度：爪持续前顶且 `v_pick>v_film` 会有压缩/拱曲风险；辊更快时可能从爪处抽走胶片。早期采用允许胶片自由离开的指尖/过行程柔顺结构，并在已确认咬合后卸载。力峰值、辊速度和退出相位同步记录。

单电机若用 `i=ωmotor/ωcam` 表示减速比，输出能力至少满足：

```text
η_g i T_motor >= T_cam,peak + k T_roller,peak + T_loss
P_motor η_total >= F_pick v_pick + F_feed v_film + P_loss
```

转动惯量、低电压启动、静摩擦与峰值不能由平均功率替代。若辊与凸轮同轴系，完成一周后再次续转会触发下一次拾片；需要可验证的长原点停留/离合设计，或采用双电机。

## 5. 三个系统概念的运输约束

| 概念 | 必须计算/验证的条件 | 当前用途 |
| --- | --- | --- |
| A 单电机、辊与凸轮机械关联 | 上节长度不等式、扭矩和相位；一周一次；停止过冲小于原点安全窗口；任何用于爪回程的反转不得带动药包中的片反退 | 完成辊/拾片数据后再评估整合 |
| B 双电机：拾片凸轮 + 显影辊 | 凸轮严格一个完整机械周；辊速度和运行时间独立；交接握住胶片后允许爪脱离回原点；出口/转速/电流共同判断 | 早期首选，便于分离拾片与显影变量 |
| C 电磁铁拾片 + 电机显影辊 | 全行程力曲线 `F_sol(x,I)`、回位弹簧、驱动电压、撞击限位、保持时间、热占空比；法向脱离仍需要机构 | 仅在实测力—行程窗口成立后选择 |

C 的校核应包括：

```text
对于全部行程：F_sol(x,I) >= F_pick(x,n)+F_return(x)+F_friction+F_margin
W_required=∫[F_pick+F_return+F_friction]dx
E_input=∫V I dt；机械能不能超过输入能
D=t_on/T_repeat；P_copper,avg=(1/T_repeat)∫I² Rcoil(T)dt
Lcoil dI/dt + Rcoil I = V_applied（忽略运动电势时的简化）
```

电磁铁吸合端的标称保持力不能代替起始大气隙处推力，标称静力也不能证明响应时间。线圈允许温升和厂家占空比必须按具体型号查验；当前没有候选型号，故不填数字、不承诺 C 可行。B 的暂选是试验可辨识性判断，不是量产体积或成本已优于 A 的结论。

## 6. 状态、检测与故障动作

推荐原型状态序列为：`READY → ROLLERS_UP_TO_SPEED → PICK → HANDOFF → FINGER_RELEASE → FINGER_HOME → TAIL_CLEAR → DONE`。其中 `FINGER_HOME` 与 `TAIL_CLEAR` 可以先后变化，但只有两者都已证实才能重新进入 `READY`。黑盖另走 `INITIALIZE_COVER`，其完成不减少 10 张计数。

原点开关只是爪周期结束信号，不证明胶片完整离开辊。优先用封闭机械触点或霍尔检测凸轮/轴位置，辊轴使用磁编码器，片尾通过可测试的机械轻触器检测。电流仅辅助识别负载异常，不独立证明单双张。

曝光面、片盒曝光口及尚未显影片附近禁止直接放置发光光电传感器。红外也不能未经雾化试验证明无影响；若最终需要光电编码器，应在与片腔隔光的封闭传动腔里。指示灯和传感器漏光要作为暗箱试验对象。

进入药包咬合后的正常路径只向前。若卡住、掉电或电流超限，停机并锁定再次拾片；不自动反转、不重复完整拾片周期。反转会把受压/已破药包的片带回片盒或再次受压，这属于待故障试验的损坏与污染风险，不能作为默认解卡方案。手动释放应在不伤片盒、可遮光且不会污染下一张的条件下试验后再定义。

停止过冲可先用 `Δθ≈ωc t_control+ωc²/(2α_brake)` 估算，其中 `α_brake` 是实测减速度。若大于原点安全角窗，则应降低原点接近速度/改变制动，不能依赖“开关已经断开”。

## 7. 可换模块及试验记录

拾片台架建议包含可拆片盒定位巢、可调后盖压片模块、可调辊位置模块和可换拾片指。更换指尖只允许改变尖端材料、厚度、圆角、尾缘挂接量及柔顺性，定位安装基准和行程标尺保持一致；任何圆角、厚度和槽位数值均待测。模块在拆卸后重新检查曝光口 datum，不能由辊 cassette 的安装改变片面定位。

每次试验记录：片盒批次/数量、黑盖或胶片、压片设定、指尖版本、行程、爪 `y/z` 轨迹、力曲线、辊速度、电流、交接相位、原点误差、单双张、划伤和未出片原因。先用已显影片与几何替身研究轨迹，再用真实未显影片验证药包和摩擦；几何替身不能证明化学显影质量。对首、中、末张以及不同安装方向分别覆盖，不能以一次成功推进作为完成证据。

进入详细设计的门槛：确定实际单张选取窗口；全盒及黑盖都能完成“推—交接—退指—原点”；最坏运输长度不等式留有实测余量；任一故障不会自动再次拾片；尺寸/力/时序记录可被复做。尚未完成这些门槛。
