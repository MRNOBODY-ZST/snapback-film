# R0 台架装配与接线入口

当前交付独立开发平台，最终相机后背尚未设计。原 RB67、旋转接环和标准相盒不做永久修改；第三方参考模型用于比对，不能直接打印当作已验证接口。

## 台架装配顺序

按各台架版本目录中的 config、README 与 manifest 加工/组装，保留版本，不覆盖后续 R1/R2。CNC 承力件、实际轴承、轴与配合由加工/量测确认；STL 为形状参考，普通 FDM 不用于精密承载轴承面或显影接触面。

先完成无电机机械基座、滑动件和止挡，测自由滑动、松动、卡滞及紧固后的变化；滚轮平台用刚性量规校对位置，量规不用于破药包。载荷、加工孔与轴承配合没有实测前不带真片测试。

拾片平台的片盒定位、真正爪尖与凸轮要在接口测量后添加。开放观察平台适合假片/已显影片；后续真片必须有验证后的遮光罩。滚轮平台的材料、工作辊隙、预载与驱动还须按 DOE 选择，不能把停车态量规间距当作显影辊隙。

## 电子接入顺序

用户负责原理图/PCB。先按 [接口合同](../electronics/pcb/interface-contract.md)确认每路功率和逻辑电平，再用独立台架板坐标绘图；台架板不声明可以塞入最终后背。

未接电机时验证电源、充电、暂停充电/ACK、ARM 默认下拉和硬件 kill；A/B 各自接限力空载负载，确认正反向定义、独立 ADC 与桥故障。不要按颜色推断针号；两电机端子都为 H 桥切换节点，不接成“电机负极=GND”。逐一验证 S0–S5 真正极性和故障诊断后才能集成调度。

当前 C++17 主机核心用于测试行为。刷写前仍须实现 MCU HAL、NVM 擦写单元与原子发布映射、实际 GPIO/ADC/PWM、时钟/看门狗及非阻塞日志，并闭合标定；不能把 TEST_ONLY 配置用于真机。

## 首次通电边界

从安全空载和假片开始；门开必须两电机失能，EJECT/LOAD 不排队，暗插在位不启动，未知标定禁止 ARM。STOP、一次有界安全 A 回退、持久化、掉电不重送都验证后再加真实片。

所有真实试验按 [testing.md](testing.md)、[calibration.md](calibration.md)记录；卡片按 [troubleshooting.md](troubleshooting.md)隔光和释放，不能反复强推。任何产品装片、后背拆装或中途保存的操作承诺要等对应物理门槛通过后写入最终手册。
