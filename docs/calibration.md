# R0 标定执行单

本文件供后续实物标定使用，没有标定结果。量测配置、原始读数与不确定度按 [measurements.md](measurements.md) 保存；焦面、图像中心与旋转检查依据 [film-plane.md](film-plane.md)。软件测试值不能回填为实测值。

## 1. 基准与焦面

先记录机身/原旋转接环型号，确定接环后承靠基准 A 和 R 坐标。使用正常装片的原 120 后背取得有效曝光层的 z_R，不能把空背压片板当作胶片面。检查重复装卸后的散布和倾角，再以磨砂面真正落在目标 R 的校准玻璃核对。

片盒在正常受压条件下测满盒、中段、末张的曝光侧表面代理与有效面。不得按压原厂禁止触碰的部位；若不能观察真实在位层，保留 MEASUREMENT_REQUIRED，通过真实片光学校验补证据。

在固定镜头、焦屏、相机和有方向的高反差靶位置下，用镜头全开比较焦屏与 R 磨砂面。近摄、实际人像距离及长距/无穷远都覆盖中心和边角。用实测厚度的可换垫片调整，记录位置和正负方向；不能重新对焦后把清楚照片当作同焦面证据。

0.05 / 0.10 / 0.20 / 0.50 mm 是用户要求的候选垫片规格，属于设计目标；实际厚度、组合、支承位置及允许误差须测定。每次向前校正后重查片盒前框、暗插和原接环腔体碰撞。

| 项目 | 输入/记录 | 验证方式 |
|---|---|---|
| 原胶片面 | z_R、装夹条件、重复定位散布 | 接触量测 + R 磨砂面光学校核 |
| Instax 在位层 | 首/中/末片、温度、片盒批号、压力 | 表面代理量测 + 真片受控焦点靶 |
| 平面倾斜 | 各角 Δz、垫片位置 | 四角比较，不能只测中央 |
| 画面中心 | 实际 62×62 图像区中心对光轴 | 带 TOP/LEFT/RIGHT 的目标，校核边界与方向 |
| 验收容许误差 | 预先定义画质指标、使用镜头与光圈 | 最苛刻工况验收，当前 null |

记录：[measurement-log.csv](../experiments/film-plane/measurement-log.csv)、[focus-log.csv](../experiments/film-plane/focus-log.csv)。

## 2. 拾片与滚轮

先在开放台架使用假片/已显影片，逐项检查片盒定位、指尖非图像区接触、单张分离、行程、回程与夹持。每次只换一个影响变量，采集位移—力、电流、视频和首/中/末/黑盖分组结果。假片厚度、刚度、摩擦须有实测记录；假片不验证布液。

滚轮先测轴颈、芯/套、径向跳动、沿宽三点间隙和左右载荷。平行度 ≤0.05–0.10 mm 是初始目标，须在真实载荷与全转角下确认。弹簧校准从力—位移曲线开始，预压用左右独立力读数定义；旋钮圈数不能自动当成 N。按 [roller-development.md](roller-development.md) 取得安全的载荷/速度窗口后再做 DOE，不能先填写虚构 Fuji 数值。

## 3. 电子标定顺序

1. A/B 均未连接时验证复位、失能、门开、硬件 kill/watchdog；确认实际 OUT 处不出现运动命令。
2. 独立标定每路电流的测量点、增益、零点、采样/滤波和 PWM 续流影响，再校准电池/VM ADC。不得将电机通道电流相加作为电池电流。
3. 校核 S0–S5 极性、断线/短路诊断、消抖和最短真实事件，夹持证明与 S4 入口检测分开；传感光须另做雾化试验。
4. 空载与假片限力运行，测时间上界、调度间隔、充电暂停及 ACK 的真实硬件作用、A 回退安全区与独立位置限位。
5. 从空载、假片、真片药包、局部卡片、硬卡片电流轨迹建立 JAM_CURRENT_THRESHOLD/JAM_TIME_THRESHOLD，验证硬限流、软停止和一次回退。阈值须有可分离裕量，不能直接用平均值或日志 P99。
6. 有界条件下验证掉电和 NVM 写入故障；pending 必须 SERVICE/计数不确定，不能自动重送。

仅在所有必需配置与标定记录核对后，才允许真实硬件以 Measured 校准模式启动。当前没有完成这些步骤。

## 4. 漏光与拆背

先用适合光谱范围的感光测试介质并设黑暗对照，再以真 Instax 验证。不同介质的“不见漏光”不能自动覆盖 Instax 的全部感光响应。分别检查暗插插入、抽出和移动中、出口待机/运动/卡片、门、接环及服务盖；强光、持续照射、旋转和拆装都记录条件。

中途拆卸测试保持片仓门关闭、暗插到底：拆下 → 重装 → 抽暗插 → 正常曝光/出片，与未拆卸对照比较。通过前不承诺亮处存半盒；开后门仍不能在正常照明中保护剩余片。记录 [light-leak-log.csv](../experiments/light-leak/light-leak-log.csv)，验收目标为无可检测漏光。
