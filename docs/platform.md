# SnapBack｜即影背：平台与适配范围

项目名称于 **2026-10-17** 从“Fully Open Motorized Instax Square Back V2 for RB67”扩展为 **SnapBack**。`snap` 呼应拍照，`back` 指可换后背；仓库名为 `snapback-film`。旧名称保留为首个机身/胶片组合的历史模块标识，不改变旧测试记录或增加硬件验证结果。

## 当前模块与扩展方向

| 项目 | 当前状态 |
|---|---|
| 平台方向 | 面向可换后背中画幅机身的开源电动即时成像后背 |
| 第一个相机适配目标 | Mamiya RB67 / Pro-S / Pro-SD，保留与机身匹配的原旋转接环 |
| 第一个胶片格式 | 商售 Fujifilm Instax Square 整盒，独立自制拾片/滚轮，不用供体相机 |
| 后续机身 | 计划扩展；尚未选择、测量、设计或验证其他机身接口 |
| 实物状态 | R0 工程准备；相机接口/焦面未闭合，送料/化学显影未实测 |

## 复用边界

共享部分候选为拾片/传送/显影子系统、双电机控制核心、传感器逻辑、计数日志、诊断与试验方法。它们是否能跨机身直接复用仍受安装方向、出口位置、空间、受力和遮光条件限制。当前是可调开发平台，没有冻结通用后背硬件接口。

每个新机身模块必须独立确定安装/锁紧基准、原有效曝光面、空腔/通光口、画面中心、暗插与独立遮光、联锁、质量承载和操作/旋转扫掠包络。增加一块转接板并不自动证明焦面能重合；不得把现有 RB67 参数复制成新机身尺寸，或把焦平面后移来躲避干涉。

每种胶片格式也须独立建立相盒/曝光面/拾片/药包/滚轮参数和真片试验。平台名不限制未来画幅，但目前没有实现 Mini/Wide 或其它胶片兼容。

适配模块使用明确的机身×胶片标识、独立参数/证据和原型版本。现有 `RB67_*` 参数、RB67 文档及历史文件名是第一模块的记录，应保留其准确含义。控制核心的逻辑接口与机身/胶片实际标定分开；未知标定仍禁止启动，不能因“平台化”绕过现有工程门槛。
