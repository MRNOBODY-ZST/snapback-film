# PCB功能接口契约：双电机首样

状态：**研究/接口草案，不可直接投板或出Gerber**。PCB由用户绘制。此文件定义功能、电平、连接顺序和机械数据交付方法；实际封装焊盘、MCU管脚复用和元件数值必须在器件选择及机械测量后校核。核对日期2026-10-07。

已另行给出 [R0 独立台架载板](R0_bench-interface.md)的 90×70 mm 自定板框、孔位、接口/逐针坐标与 JSON/SVG，可用于开发画板。本文下方的安装尺寸指最终装机板，仍未冻结；两种用途不要混用。

## 2. 功能与电平

逻辑/数字传感器统一3V3；电机端为H桥功率节点。`BAT_RAW`只在电芯保护输入侧；系统使用受保护电池端与充电器SYS，不混用命名。不得将USB VBUS、充电器4.5V SYS或满电电池直接接3V3输入/ADC。ADC范围由最终MCU参考与器件限制确定。

| 信号 | 方向（以主控板为中心） | 定义/默认状态 |
|---|---|---|
| S0 `PACK_PRESENT_N` | 输入3V3 | 低有效=片盒在位；开路/断线默认高=不在位 |
| S1 `DOOR_CLOSED_N` | 输入3V3并接硬件联锁 | 低有效=门已完全闭合；断线高禁止A/B |
| S2 `DARK_SLIDE_INSERTED_N` | 输入3V3 | 低有效=相机暗板插入；首样禁止EJECT/LOAD启动 |
| S3 `PICKUP_HOME_N` | 输入3V3、快速事件 | 低有效=拨片在安全home；每循环必须先离位再返回 |
| S4 `ROLLER_ENTRY_N` | 输入3V3、快速事件 | 低有效=片材占据滚筒入口检测点；接管依据 |
| S5 `FILM_EXIT_N` | 输入3V3、快速事件 | 低有效=片材占据出口检测点；完整出现/释放为出片证据 |
| A_IN1/A_IN2，B_IN1/B_IN2 | 输出3V3 | 两路独立正反转/PWM命令；硬件下拉；失能时两脚强制0 |
| A_ARM、B_ARM | 输出3V3，分别经硬件联锁 | 高才可运动；上电、复位、掉电、未安装程序均默认0；不是DRV8213RTE虚构的nSLEEP脚 |
| MOTOR_KILL_LATCH | 硬件联锁与主控状态 | 门开、欠压、看门狗/故障后锁存失能；JAM只允许在已验证安全区一次有限回退后再次STOP并锁存；人工检查处理卡片及核对位置后才可清除/重新arm，无自动前进重试 |
| ADC_I_A、ADC_I_B | 独立模拟输入 | 每路驱动电流信号；不同于电池总电流；标定增益/偏置/参考 |
| ADC_VBAT | 模拟输入 | 受保护电池电压分压、滤波；禁止电池原压直入ADC |
| ADC_VM（建议预留） | 模拟输入 | 电机电源监测；区分电池好而升压轨下陷 |
| A_FAULT_N、B_FAULT_N | 开漏3V3输入 | 每路驱动故障独立；如选DRV8213RTE可另读nSTALL，不依赖自动重试 |
| CHG_STAT1_N/CHG_STAT2_N、VBUS_PRESENT | 输入3V3 | 接正确上拉/电平转换后的充电状态与输入存在 |
| CHARGE_PAUSE | 输出 | 循环前禁止充电，循环完且静止后恢复；极性按所选充电器映射 |
| SENSOR_PWR_EN / EMITTER_EN | 受控输出 | 探测器/发光器供电控制；发光器默认关闭，电流需专门驱动 |
| BTN_EJECT_N、BTN_LOAD_N | 输入3V3 | 低有效按钮，经消抖；按下不等于完成出片；重装计数必须明确新盒流程 |

“低有效”只规定信号语义，不证明单线传感器完全具故障诊断。S2断线会假装暗板已取出、S4/S5断线会假装清空，启动自检与运动事件序列必须识别无响应；若首样需要上电即可诊断断线，使用终端电阻/模拟窗口或第二触点，另占ADC/管脚，并冻结正常/断线/短路窗口。

S0–S3优先评估机械开关或Hall+磁体等无照明方案；其安装触发位置仍待几何验证。S4/S5接触式测片要测接触力/摩擦，不得划伤或改变滚压。若改用光电探测，不可把“红外”当作天然不感光：波长、光路封装、漏光、占空比和对未曝光材料的雾化影响须有实际片材试验。发射器不能由MCU引脚直接承担未经核算的电流；模拟接收器用ADC/比较器转换并保存校准条件。界面规格与器件规格分别冻结。

## 3. 建议线束端口编号与引脚顺序

下表是**逻辑针序提案**，与最终接插件制造商焊盘编号须一一映射，不能仅凭线色或看图方向插接。电机端应有防错键位并与电池端不互配。

| 端口 | 针序提案 | 功能/位置要求 |
|---|---|---|
| J_MA | 1=A_OUT1，2=A_OUT2 | 拨片电机功率端；靠近A线束出口但远离S4/S5敏感模拟线；电机正转方向实物验证后在电机和线束两端标识 |
| J_MB | 1=B_OUT1，2=B_OUT2 | 滚筒电机功率端；两脚均为切换节点，任何一脚都不是固定GND |
| J_S0…J_S5，各3针 | 1=GND，2=对应Sx_N，3=SENSOR_3V3 | 干触点传感器只用1/2，3留空；有源传感器输出须3V3兼容开漏或受控电平，不给5V供电 |
| J_ENTRY_OPT / J_EXIT_OPT（仅光电选项） | 1=AGND，2=SENSOR_3V3，3=RX_ANALOG，4=EMITTER_DRIVE，5=EMITTER_RETURN | 防止把模拟接收脚插入3针数字口；发射器电流/电压待器件选定；不默认可照射暗腔 |
| J_BAT | 1=P+，2=P−，3=NTC | 受保护1S电池包接口；NTC另一端按所选充电器参考回路；裸电芯使用板上保护时改为单独RAW端口并重新审核命名 |
| J_UI | 1=GND，2=BTN_EJECT_N，3=BTN_LOAD_N，4=LED_READY_DRV，5=LED_FAULT_DRV | LED带限流/驱动；显示电流不影响运动信号；新盒确认与普通EJECT区别明确 |
| J_DISPLAY（可选） | 1=GND，2=3V3，3=I2C_SCL，4=I2C_SDA | 计数/不确定状态显示；不把显示I2C作为关键运动联锁 |
| J_UART | 1=GND，2=3V3_REF，3=MCU_TX，4=MCU_RX | 3V3调试串口；REF为电平参考，外置适配器不得反向供电主板 |
| J_SWD（STM32候选） | 1=GND，2=VTREF_3V3，3=SWDIO，4=SWCLK，5=NRST | 调试/下载；与电机控制复用前先保证上电失能。正式针序可改标准连接器，但须同步线束文档 |
| J_UPDI（ATtiny候选，替代J_SWD） | 1=GND，2=VTREF_3V3，3=UPDI | 不与J_SWD同时假定存在；高压恢复功能与外部电路兼容性须另核查 |
| TP_ANALOG | GND、3V3、ADC_I_A、ADC_I_B、ADC_VBAT、VM | 测试点，不承载大电流；用示波器记录交接与欠压 |
| TP_DRIVE | A_ARM、B_ARM、A_IN1/2、B_IN1/2、KILL | 证明复位/门开时驱动确已失能 |

J_MA/J_MB不应在同一个小信号传感器插头上共用。线束长度、线径、端子触点、最大正反向电流和温升都属于最终BOM条目，不能由“JST”通用名称推定承载能力。

## 4. 双路驱动与失能链

DRV8213RTE候选为每电机一颗，RTE具IPROPI、外部VREF、nFAULT/nSTALL；DSG接口不同。RTE VM可0–11V，VCC1.65–5.5V，峰值4A；要按热与PCB铜面积核定实际限流。[TI DRV8213数据表](https://www.ti.com/lit/ds/symlink/drv8213.pdf)

每路独立电流限幅、ADC与ARM门控。外部逻辑将对应IN1/IN2与`ARM && door_closed && rail_ok && !kill_latched`相与；上电门控默认阻断，启动后仅有效intent允许ARM。软件的PWM=0不是唯一关断机制。门开/危险欠压为硬件优先事件；S2首样作为启动联锁，运动中停止策略按已验证机械处理。

在不同PWM/续流模式下电池侧分流未必等于电机绕组电流，外部检测方案须明确测量点、带宽、续流死区与校准。[TI DRV8837数据表](https://www.ti.com/lit/ds/symlink/drv8837.pdf) ADC和电流镜信号远离OUT1/OUT2与开关电源节点；功率回流不经过传感器地线。两个桥旁各有数据表要求的去耦和按实测瞬态确定的储能电容，不把一颗USB口电容当作所有负载的储能。

卡片故障的外部ARM/失能链必须支持`STOP → 一次安全有界A回退（有条件） → STOP → JAM锁存`；不能由驱动器内部自动重试恢复桥输出，也不能提供循环强推故障片的服务命令。回退前持久化标志，回退后保留锁存；人工检查并证明空载或安全dummy状态后，才允许新的人工死手点动测试。

## 5. USB-C充电与开发调试

USB-C端口首先是5V受电端；CC1/CC2各有独立Rd；电流输入权限由CC/USB连接条件决定。[Espressif USB-C硬件指南](https://docs.espressif.com/projects/esp-iot-solution/en/latest/usb/usb_overview/usb_typec_hardware_guide.html) VBUS输入保护、GND/屏蔽和ESD布置须按所选器件/连接器图纸。第一阶段不声明PD高压或快充。

STM32C031K6采用SWD下载、UART日志；C031数据表列出的串行外设不包含USB控制器。[ST 数据表](https://www.st.com/resource/en/datasheet/stm32c031c6.pdf) 若用户希望一个USB-C口同时充电和开发日志，可加CP2102N USB-UART桥，把USB2 D+/D−接桥而非直接接C031；CP2102N支持USB2全速和UART，QFN20机体3×3mm。[Silicon Labs 数据表](https://www.silabs.com/documents/public/data-sheets/cp2102n-datasheet.pdf) 串口桥供电、VBUS检测/分压、暂停状态与反向供电按该版数据表完整审查；不从其3V3输出直接供整个电机系统。首样也可先用外置3V3 USB-UART适配器和SWD探针，减少板内复杂度。

若改用ESP32-C3，原生USB Serial/JTAG会占相关GPIO且受启动配置约束；不能同时把同一D+/D−硬连到CP2102N。[Espressif 模组数据表](https://documentation.espressif.com/esp32-c3-mini-1_datasheet_en.pdf) 固件下载、日志、服务点动接口均必须保持电机默认禁用；不允许USB插入直接触发出片。
